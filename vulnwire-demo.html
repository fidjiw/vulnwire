API 文档

REST + SSE · 时间均为 UTC+8 · Base URL https://api.vulnwire.example.com

v1 · 稳定
快速开始与认证 实时流（SSE） 情报查询 POC 查询 订阅管理 Webhook 回调 限流与错误码

快速开始与认证

所有请求使用 Bearer Token 认证。Token 在「设置 → API」中生成，可按用途开多个、独立吊销。以下示例使用只读演示 Token。

vw_live_9f2e••••••••••••3ab7 只读 · 2026-11-30 到期 
# 拉取当前「严重 + 已有 POC」的情报
curl -N "https://api.vulnwire.example.com/api/v1/feed?severity=critical&poc=true" \
  -H "Authorization: Bearer vw_live_9f2e…3ab7"

GET 实时流 /api/v1/stream

SSE 长连接，事件类型：intel（新情报）、poc（POC 入库）、kev（KEV 新增）。服务端每 25 秒发送一次注释心跳；断线请用 Last-Event-ID 续传。

event: intel
data: {"id":"CVE-2026-31287", "severity":"critical", "cvss":9.8,
       "poc":"exploited", "matched_assets":["Confluence 生产集群"],
       "title":"Atlassian Confluence — OGNL 注入 RCE"}

: ping (every 25s)

GET 情报查询 /api/v1/vulns

参数说明
severitycritical | high | medium | low，逗号分隔多选
q关键词（CVE 编号 / 产品 / 标题全文）
poc / kevtrue 时仅返回已有 POC / 在野利用条目
page · size分页，size 上限 100
 
{"total":156, "items":[{"id":"CVE-2026-31287", "cvss":9.8,
  "epss":0.94, "kev":true, "pocs":[{"repo":"…/confluence-rce-auto",
  "stars":2100, "verified":true}], …}]}

GET POC 查询 /api/v1/pocs

仅返回元数据与跳转链接，不托管代码。参数：q、type（rce / sqli / ssrf…）、verified=true、since（ISO 时间）。

curl "https://api.vulnwire.example.com/api/v1/pocs?q=confluence&verified=true" \
  -H "Authorization: Bearer vw_live_9f2e…3ab7"

POST 订阅管理 /api/v1/subscriptions

创建订阅；DELETE /api/v1/subscriptions/<id> 删除。条件结构与页面「规则构建器」一致。

curl -X POST "https://api.vulnwire.example.com/api/v1/subscriptions" \
  -H "Authorization: Bearer vw_live_9f2e…3ab7" \
  -d '{"name":"核心产品高危",
       "conditions":[{"field":"cvss","op":"gte","value":7.0}],
       "channels":["dingtalk","email"]}'

Webhook 回调

推送失败按 1 / 5 / 15 / 60 分钟指数退避重试最多 5 次。每条请求带签名头，校验方式：HMAC-SHA256（raw body, webhook secret）。

X-VulnWire-Signature: sha256=5f3a…c91d

{"event":"rule.matched", "rule":"核心产品高危告警",
 "cve":"CVE-2026-31287", "delivered_at":"2026-08-24T11:47:03+08:00"}

限流与错误码

套餐REST 请求SSE 并发连接
免费60 / 分钟1
专业（私有部署）600 / 分钟5
错误码含义
401Token 缺失 / 失效
403权限不足（如只读 Token 调写接口）
429触发限流，按 Retry-After 头退避
5xx服务异常，可安全重试（幂等）
